# World Cup 2026 Match Predictor

Forecasts 2026 FIFA World Cup outcomes by pairing **Elo ratings** with a
**Dixon-Coles adjusted Poisson scoreline model**, then runs a **10,000-trial
Monte Carlo simulation** of the full 48-team, 12-group tournament to produce
title / advancement odds per team. Backtested against historical results,
scoring forecasts on accuracy and Brier score.

## How it works

1. **Elo ratings** (`src/elo.py`) — the public "World Football Elo Ratings"
   formula: win expectancy from the rating gap plus home advantage, updated
   after each match by a K-factor (scaled by competition importance) times a
   goal-difference multiplier.
2. **Dixon-Coles model** (`src/dixon_coles.py`) — converts the Elo gap
   between two teams into expected-goal rates (λ, μ), builds the bivariate
   Poisson scoreline matrix, and applies the Dixon & Coles (1997) τ
   correction that fixes Poisson's tendency to under-predict low-scoring
   draws (0-0, 1-1) relative to real football data.
3. **Monte Carlo simulation** (`src/simulate.py`) — samples a scoreline for
   every match from the model, plays out all 12 groups (top 2 + best 8
   third-place teams advance, matching the actual 2026 format), then a
   32-team single-elimination bracket with a probability-weighted shootout
   for knockout draws. Repeated 10,000 times to get stable odds.
4. **Backtest** (`src/backtest.py`) — walks forward through a dated match
   history, predicting each match *before* it updates the ratings, then
   reports decisive-match accuracy and Brier score.

## Run it

```bash
pip install -r requirements.txt

# regenerate the demo match history (synthetic, see note below)
python src/generate_sample_data.py

# backtest the model
python src/backtest.py

# simulate the tournament and print title odds
python run_simulation.py --sims 10000

# run the test suite
pytest
```

## Data

- `data/seed_ratings.csv` — illustrative starting Elo ratings for 48 teams.
  Swap in real current ratings (e.g. from a maintained Elo source) for
  production use.
- `data/groups.json` — an illustrative pot-seeded 12-group draw for demo
  purposes; swap in the real 2026 draw once it's finalized.
- `data/sample_historical_matches.csv` — **synthetic** match history
  generated by `src/generate_sample_data.py` from the seed ratings, used so
  the backtest has a self-consistent dataset to walk through out of the box.
  It is not a record of real results. To backtest against actual football
  history, point `src/backtest.py` at a real dated results CSV with the same
  columns (`date,home_team,away_team,home_goals,away_goals,stage,neutral`).
